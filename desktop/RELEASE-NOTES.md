# CubeLink Starter Windows 1.9.0 (test release)

- Windows x64 installer with Arduino tools included. No separate Bridge or Node installation.
- Free local AI conversation inside the app: no account, API key or per-message billing.
- On first use, click the free AI preparation button to download the official Qwen3-0.6B Q8 model (about 640MB). Downloads are checksum-verified. Subsequent conversations run on your PC without sending messages to an online AI service.
- This is a small local model, not ChatGPT. Speed and answer quality depend on the PC; verify wiring and code. 8GB RAM or more is recommended. A working internet connection is required for the first model download.
- Existing 18 lessons, simulation, live mode and uploads are retained.
- Unsigned test installer. Windows may show an unknown-publisher notice. Physical USB upload and sensors still require board testing.

AI runtime: llama.cpp b12465 (MIT). Model: Qwen/Qwen3-0.6B-GGUF revision 23749fefcc72300e3a2ad315e1317431b06b590a (Apache-2.0). Licenses are included in the app resources.
