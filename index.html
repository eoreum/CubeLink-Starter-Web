오늘 바로 시작하는 아두이노
① LED 예제를 불러오고 실행하세요. ② 대기 시간을 바꿔 보세요. ③ setup의 OUTPUT 블록을 지우고 출력 차단 경고를 관찰하세요.
큐브링크 스튜디오와 같은 Blockly 블록입니다. 왼쪽 분류에서 블록을 끌어 setup/loop 안에 맞물리게 연결하세요. 블록은 우클릭 메뉴 또는 Delete 키로 삭제합니다. 연결되지 않은 블록은 실행하지 않습니다. 실행 중 편집하면 시뮬레이션은 정지합니다.
센서는 핀별 입력을 공유합니다. LDR/가변저항은 0~1023 ADC 원시값이며 실제 LDR 밝기 방향은 분압 배선에 따라 달라집니다. 버튼은 INPUT_PULLUP일 때 GND로 눌러 0, 놓으면 1입니다. INPUT의 연결되지 않은 핀은 실제로 불안정하지만 이 데모는 0으로 단순화합니다.
초음파는 HC-SR04 개념 모델입니다. Trig OUTPUT, Echo INPUT을 직접 설정하세요. 무응답은 -1 cm이며 실제 보드에서는 30ms 타임아웃을 사용합니다. 출력 모드 누락 시 시뮬레이터는 digitalWrite를 차단하지만 Arduino 하드웨어 자체는 INPUT에서 풀업 상태를 바꿀 수 있습니다.
화면 크기 조절
창 크기에 자동으로 맞춥니다. 화면 맞춤은 분할 비율을 초기화합니다. 코드 옆 세로 분할선과 회로 위 가로 분할선을 드래그하거나 방향키로 조절하세요. 블록 맞춤은 연결된 블록 전체를 보이게 하고, 블록 크기는 글자 크기를 조절합니다. 전체 화면은 버튼으로 켜고 Esc로 해제합니다. 화면에는 디스플레이 해상도와 실제 앱 영역(CSS px)을 구분해서 표시합니다.
실제 하드웨어 연결
데스크톱 Chrome의 localhost 또는 HTTPS에서 USB 시리얼 연결 버튼을 누르면 최초 포트 선택 권한이 필요합니다. 9600 baud로 연결하며 포트 열기로 보드가 리셋될 수 있습니다. Arduino IDE 시리얼 모니터 등 다른 프로그램이 포트를 사용 중이면 닫으세요.
이 앱에는 직접 업로드 기능이 없습니다. Web Serial 연결은 텍스트 송수신만 지원합니다. 생성한 .ino를 Arduino IDE로 업로드하세요. 블록으로 실제 핀을 실시간 제어하려면 호환 펌웨어/브리지 또는 별도 업로드 구현이 필요합니다. 시뮬레이션 실행 버튼은 실제 보드를 제어하지 않습니다.
